# Hospital Management System

React + Vite + Tailwind CSS starter project.

## Run locally

1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite in your browser.

## Included pages

- Login (demo: any non-empty email and password)
- Dashboard
- Patients Management (add and delete patients)

## Notes

- Tailwind CSS is configured through `@tailwindcss/vite`.
- `src/index.css` must remain and contains `@import "tailwindcss";`.
- The current patient and dashboard data is demo data stored in the frontend only. It is not connected to a database.
